## Quyết định quan trọng & lý do

- **Chat AI dùng agentic tool-use loop thay vì forced tool-call 1 lần** (khác mọi AI service trước đó) — vì chat cần Claude tự quyết định có cần tool hay không, gọi tool nào, có thể chain nhiều tool trước khi trả lời tự nhiên. Đây là lần đầu project cần `tool_choice` auto + loop thay vì ép buộc.
- **Chat AI chỉ read-only, không lưu lịch sử DB** — 2 quyết định phạm vi đã xác nhận với user qua AskUserQuestion trước khi code, giữ nhất quán triết lý "AI làm giàu trải nghiệm, không tự hành động" đã áp dụng cho AI照合 và Dashboard comment; tránh thêm rủi ro sửa tay `ApplicationDbContextModelSnapshot.cs` cho tính năng chưa cần audit trail.
- **companyId cho mọi tool luôn lấy server-side từ JWT** — không bao giờ nhận từ input Claude, kể cả khi tool schema về mặt lý thuyết có thể để model tự cung cấp — chặn cross-tenant leak dù model "tự chế" giá trị.
- **/wrap-up bỏ hoàn toàn bước Git** — môi trường Claude Code hiện tại không có `git.exe` khả dụng qua PowerShell tool (đã thử tìm ở `Program Files`, `Program Files (x86)`, PATH — không thấy). User sẽ tự quản lý git qua terminal/VSCode riêng.
