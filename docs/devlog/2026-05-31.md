### Bug 2: Delete document trả 400 Bad Request
**Root cause**: File upload lưu file với tên = 書類名 do user nhập (ví dụ "契約書" không có extension). Các endpoint `Download`, `DeleteFile`, `BulkDelete` validate `Path.GetExtension(filename) != ""` → fail với extensionless names.

**Thêm**: `DeleteFileAsync` local implementation dùng `PhysicalFileProvider(filePath)` với file path (không phải directory) → file không thực sự bị xóa khỏi disk, chỉ xóa DB record.

**Fixes**:
- `backend/CaseMngmt.Server/Controllers/FileUploadController.cs`: Xóa extension check khỏi cả 3 actions (`Download`, `DeleteFile`, `BulkDelete`)
- `backend/CaseMngmt.Service/FileUploads/FileUploadService.cs`: Thay `PhysicalFileProvider` bằng `File.Exists` + `File.Delete` trong `DeleteFileAsync` local path

### Bug 3: MUI Autocomplete warning
- **File**: `frontend/src/components/until/FormSelection.js`
- **Fix**: Thêm `isOptionEqualToValue` (handle GUID string vs object) và `getOptionLabel` (handle string option vs object option)
- Fix propagate tới TẤT CẢ màn hình dùng FormSelection: CaseDetail, CaseSearch, DocumentSearch, Upload, admin pages

### Bug 4: Case form hiện customer khác 顧客検索
**Root cause**: `TemplateService` gọi `CustomerRepository.GetAllAsync()` (no CompanyId filter) → hiện tất cả customers. `CustomerController` gọi overload có filter → chỉ hiện customers của company.

**Fixes**:
- `backend/CaseMngmt.Repository/Customers/ICustomerRepository.cs`: Thêm overload `GetAllAsync(Guid companyId)`
- `backend/CaseMngmt.Repository/Customers/CustomerRepository.cs`: Implement overload mới, filter `x.CompanyId == companyId`
- `backend/CaseMngmt.Service/Templates/ITemplateService.cs`: Update signature `GetCaseSearchModelByIdAsync` và `GetDocumentSearchModelByIdAsync` để nhận `companyId`
- `backend/CaseMngmt.Service/Templates/TemplateService.cs`: Implement changes, dùng overload có CompanyId filter
- `backend/CaseMngmt.Server/Controllers/CaseController.cs`: Truyền `Guid.Parse(companyId)` vào `GetCaseSearchModelByIdAsync`
- `backend/CaseMngmt.Server/Controllers/DocumentController.cs`: Truyền `Guid.Parse(companyId)` vào `GetDocumentSearchModelByIdAsync`
